
# Exercise 6: Real-Time Operations Monitoring and Alerting

## Objective
Monitor delivery operations using Python, Prometheus, Grafana, Docker, and Jenkins.

## Metrics
- Total deliveries
- Pending deliveries
- Deliveries on the way
- Average delivery time

## Monitoring
Prometheus collects application metrics, Grafana visualizes them, and Prometheus alert rules detect high pending deliveries and long delivery times.

## Tools
- Python
- Prometheus
- Grafana
- Docker
- Jenkins
