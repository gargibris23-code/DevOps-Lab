\# Exercise 7: Introduction to Continuous Integration (CI) and Jenkins



\## Objective

\## What is Continuous Integration?

Continuous Integration is a software development practice in which code changes are frequently integrated into a shared repository. Automated checks help identify errors early.



\## Benefits of CI

\- Early detection of bugs

\- Faster development

\- Improved collaboration

\- Better software quality

\- Automated verification of code changes



\## Jenkins

Jenkins is an open-source automation server used to automate building, testing, and deploying software.
